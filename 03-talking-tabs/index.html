Session 03

My Browser Tabs Are Talking Behind My Back

Run of show

  1. Open 3 windows side by side (O). Links stretch across the gaps.
  2. Drag a window around — the links follow it.
  3. Turn Wi-Fi off. Still works: no server.
  4. Chat, flash, hijack titles. Show the gossip panel.
  5. Throw the ball (B), then close the leader tab — the ball keeps going.

One-liners

  • BroadcastChannel = a radio frequency shared by tabs of one site.
  • Heartbeat 20×/s: name, colour, window.screenX/Y.
  • Silent for 1.5 s → presumed dead (failure detection).
  • Oldest tab runs the physics (leader election).
  • Real use: log out everywhere at once; pause the other tab's video.
